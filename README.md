## Локальный запуск

Из этой папки:

```sh
python3 -m http.server 8031
```

Откройте http://127.0.0.1:8031/ на экране телефона или в мобильном режиме браузера.

## GitHub Pages

Сборка не требуется. Для отдельного сайта загрузите содержимое папки в новый репозиторий, выберите Settings → Pages → Deploy from a branch → main / (root).

Исходный remote `origin` указывает на репозиторий шаблона; для публикации отдельного приглашения используйте новый репозиторий.
